# Keyboard Shortcuts

The application works best with keyboard navigation.

## Navigation
- **Arrow Keys**: Move Up/Down/Left/Right
- **H / J / K / L**: VIM-style navigation (Left / Down / Up / Right)

## Game Actions
- **Number Keys (1-9)**: Enter number / Toggle note (if Note Mode is on)
- **Backspace / Delete**: Clear cell
- **U**: Undo last move
- **N**: Toggle Notes Mode (Pencil)
- **V**: Toggle Validation Mode (Check)
